# 二重信号機（視覚正本・compact）

compact では **1 行以上を必須**（`html-compact-template.md` の論理順）。DOM 上は **`id="iyt-dual-signal"`** を [html-structure.md](html-structure.md) の `.section-card` 内に置く（読み順は [exemplar.md](exemplar.md)）。実装ブレを防ぐため **3 灯まで**に限定する。

## 構造（ASCII ワイヤー）

```
 [ 勢い ]     [ 警告 ]
   (緑)        (黄/赤)
    ●            ●
 話題の熱量   VIX等の体温
```

## 3 状態の定義

### 左: 話題の勢い（トレンド・YouTube 本数のまとまり）

| 灯 | 意味 | 入力の目安（例） |
|----|------|------------------|
| **緑** | 活発 | トレンド・採用動画が所定に近い |
| **黄** | 普通 | 中間 |
| **灰** | 静か | 採用 ch が半分以下など |

### 右: 市場の注意（断定しない）

| 灯 | 意味 | 入力の目安（例） |
|----|------|------------------|
| **緑** | 穏やか | VIX 中位帯、裏取りは概ね整合 |
| **黄** | 注意 | VIX 上昇、または未確認が目立つ |
| **赤** | 強い注意 | VIX 急伸、`contradicted` が複数 等（**売買指示に変換しない**） |

## 表示ルール

- **テキスト＋ Lucide** で可。色だけに依存しない（必ず日本語ラベル）。  
- 数値は **取得日時つき**で L3 と整合。

## HTML マーク（必須）

```html
<section id="iyt-dual-signal" aria-label="話題の勢いと市場の注意度" class="...">
  <!-- 1 行以上。3 灯はアイコン＋短い日本語 -->
</section>
```

## 禁止

- 「買い／売り」への直接変換ラベルは付けない。
