# 裏取り（Phase 5 正本）

## 目的

YouTube 主張（L1）を、**ニュース一次**と **X 二次** で位置づけ、**断定はしない**。

## 検証ラベル（内部キー・HTML では使わない）

| 内部キー | 意味 |
|----------|------|
| `supported` | 複数の信頼できる報道と整合 |
| `contradicted` | 信頼できる報道と明確に矛盾（時系列・数値・公式発表） |
| `partially_supported` | 一部のみ整合 |
| `timing_mismatch` | 方向性は近いが時期・織り込みの取り違え |
| `out_of_scope` | ニュース検証の対象外（純技術・個人体験のみ等） |
| `unverified` | 一次が不足し確認不可 |

## 読者向け表示ラベル（HTML 必須・内部キーは出さない）

| 内部キー | 表示用日本語（例） |
|----------|-------------------|
| `supported` | 報道と整合 |
| `contradicted` | 報道と矛盾 |
| `partially_supported` | 一部のみ整合 |
| `timing_mismatch` | 時期の取り違いの可能性 |
| `out_of_scope` | ニュース検証の対象外 |
| `unverified` | 一次不足のため未確認 |

## ソース階層

1. **一次**: 報道機関の事実記述、当局・取引所・企業の公式発表。  
2. **二次**: X の市場参加者コメント（**SNS上の見立て**と明記）。

## 日本語中心 + 英語必須クラスタ

- **通常クラスタ**: 裏取りの本文素材は **日本語ニュース**を主とする（`sources-news.md`）。  
- **`requires_en_primary: true` のクラスタ**（米株・金利系）:  
  - **Phase 5a（英語一次）**: Reuters 等から **事実・数値・見出し**を短く抽出（内部メモ可）。  
  - **Phase 5b（日本語L2）**: 読者向けの **日本語要約**と検証ラベル（上表の日本語）。**HTML の本文は 5b 以降のみ**を根拠にする。

## X の扱い

- 論点ごとに **厳選**（多すぎない）。  
- 一次未確認のときは **「SNS上の見立て（一次未確認）」** と明記。

## 製作メタ禁止

「検索では取れなかった」「エージェントが」等の**製作都合**は公開文に書かない。読者向けは **切り口宣言・検索キーワード提案** に留める（diagram-invest の Phase 3 精神に合わせる）。
