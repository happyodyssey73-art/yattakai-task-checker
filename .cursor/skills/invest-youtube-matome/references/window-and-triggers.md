# `{動画鮮度窓}` と週次トリガー（正本）

## 時刻基準（必須）

- **`as_of`・`published_at` の解釈・2d/7d の境界はすべて日本標準時（JST）** とする。  
- ISO-8601 ではタイムゾーン **`+09:00`** を付ける（例: `2026-04-24T21:00:00+09:00`）。

## 値

| 値 | 意味 |
|----|------|
| `2d` | 実行基準日時（JST）から **2日以内** に公開された動画のみ採用候補（**既定**）。 |
| `7d` | 実行基準日時（JST）から **7日以内** のみ採用候補（週次まとめ時）。 |

## 絶対ルール

- **公開から8日以上前の動画は、理由の如何を問わず採用しない。**  
- `{動画鮮度窓}` は **`2d` か `7d` のいずれか**。それ以外の値は使わない。

## `7d` への切替条件（自動）

ユーザーの依頼文に、**週次まとめの意図**が含まれるときは `{動画鮮度窓} = 7d`。

### トリガー語（例・正本）

次を含む（表記ゆれを許容）:

- 「1週間分をまとめて」「1週間まとめ」「この1週間」  
- 「今週の分」「今週まとめ」「今週のYouTube」  
- 「週次」「週間ダイジェスト」

### 誤爆に注意する例

- **「来週」「先週だけ」** など、文脈が「今週の週次まとめ」とは限らない場合は、ユーザーに一言確認するか `2d` のままにする。

## 既定（自動）

上記トリガーが **なければ** `{動画鮮度窓} = 2d`。

### 例外（データ取得 CLI の既定）

チャット本文に週次トリガーが無くても、**機械収集（`scripts/phase0/phase0_make.mjs`）だけは既定を `7d`** とする。理由は、窓が `2d` のときに **各チャンネルが「今回スキップ」に偏りやすく**、比較表の素材が薄くなるのを避けるため。  
SKILL の対話既定（上の `2d`）と二重定義に見えるが、**「人間が短く見る回＝2d」「一括収集の安定性＝7d」**の役割分担である。チャットで明示された `{動画鮮度窓}` は CLI の `--window` で上書きする。

## HTML への必須表示

ページ冒頭（またはメタ）に、次のいずれかを固定文言で出す。

- `2d` のとき: **「対象動画: 直近2日以内に公開された相場系動画（基準: JST）」**  
- `7d` のとき: **「対象動画: 直近7日以内に公開された相場系動画（基準: JST）」**

## `{ニュース鮮度}` との関係

- `{動画鮮度窓}` は **YouTube 採用のみ** に適用する。  
- ニュース・X・トレンドの鮮度は **`{ニュース鮮度}`**（別パラメータ。既定は直近24時間中心）。  
- 過去の金融史・類似事例は `{ニュース鮮度}` の外でも参照可（SKILL.md の方針）。
