# クラスタリング（正本）

## 目的

「全市場ダイジェスト」でも、**同じ話題の束**の中だけ比較表を作り、読者の「一致／不一致が一目」を成立させる。

## 手順

1. その回の全 **主張カード** の `tags` を集計する。  
2. タグの重なりと `reason_type` で、**2〜5個**のクラスタに分割する（既定 **最大5**）。  
3. クラスタ名は **読者向け短名**（例: 「米金利と株」「円安と輸出」「地政学と原油」）。  
4. **比較マトリクス・裏取りストリップ・代表対立**は **クラスタ単位**で生成する。

## 上限（compact）

| 項目 | 既定 |
|------|------|
| クラスタ最大数 | **5** |
| 1クラスタあたり最大チャンネル数 | 実データに従う（非表示chは除く） |
| 1ページに **全面展開** するクラスタ数 | **3** まで。超える分は `<details>` 折りたたみまたは「続きは別出力」 |

## 小さすぎるクラスタ

- カードが **1枚だけ** のクラスタは、可能なら近いタグに **マージ**。マージできない場合のみ単独クラスタとし、比較表は「参考」とし**代表対立は付けない**（ラベル対象外）。

## 米株・金利クラスタのフラグ

タグまたは `reason_type` が **金利・FRB・米株指数・ハイテク金利感応**を主に含むとき、そのクラスタに `requires_en_primary: true` を付与し、`verification-rubric` の **5a/5b** を必須とする。
