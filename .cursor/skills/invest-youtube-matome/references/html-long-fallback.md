# long HTML（フォールバック・正本）

`compact` が読み損ねる・証拠が薄い・クラスタ過多などの理由で `{出力モード}=long` に切り替えるときに使う。

**骨格・読み順**は [html-structure.md](html-structure.md)・[exemplar.md](exemplar.md) を維持し（`iyt-read-path` 等）、**`id="iyt-character-dialogue"` の短いキャラ対話は必ず残す**（[html-character-dialogue.md](html-character-dialogue.md)）。長文化は **その外側にセクションを縦に足す** イメージにする。

## diagram-invest に近い追加セクション（例）

1. キャラ紹介バナー（初見向け・短く）  
2. クラスタごとの **背景・なぜそう言えるか**（歴史・類似事例を短く）  
3. 用語ボックス（初出用語）  
4. **ニュース整理**を表形式で拡張（媒体を増やしてよいが製作メタは禁止）  
5. **市場データ**を表で拡張（セクター、主要指数）  
6. **過去類似事例**（1〜2件）  
7. 強気/弱気シナリオ（**シナリオであり助言ではない**）  
8. 「今日から一つだけ調べること」（行動は調査・記録に限定）  
9. 免責・フッター

## 原則

- **主役は依然として YouTube 主張の整理**。長文化は **補助**であってニュース長文ブログにすり替えない。  
- 対話は `dialogue-generation-youtube.md` に従い増量可。
